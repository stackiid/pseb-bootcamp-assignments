# Forge Fitness

A responsive gym and workout landing page built with semantic HTML5 and an external CSS file.

## Open the webpage

1. Open `index.html` in a modern browser.
2. Keep an internet connection available for the remote Pexels photography and Google Fonts.
3. No build tools or JavaScript are required.

## Project structure

- `index.html`: page content and semantic structure.
- `styles/style.css`: all visual styling, layout, responsive rules, and colour tokens.
- `ASSIGNMENT-NOTES.txt`: instructor theory questions, CSS examples, and external stylesheet steps.

## Design direction

Forge Fitness uses a charcoal and electric-lime palette, strong condensed typography, editorial image crops, and responsive sections. The page includes navigation, hero, training programs, facility feature, opening schedule, and contact call to action.

## Image credits

Photography is loaded from Pexels. The page uses the four image URLs supplied in the assignment and additional Pexels photo pages selected for gym imagery. See `ASSIGNMENT-NOTES.txt` for links.
