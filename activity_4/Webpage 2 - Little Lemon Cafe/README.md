# Little Lemon Cafe

A responsive cafe landing page built with semantic HTML5 and an external CSS stylesheet.

## Open the webpage

1. Open `index.html` in a modern browser.
2. Keep an internet connection available for Pexels photography and Google Fonts.
3. No build tools or JavaScript are required.

## Project structure

- `index.html`: semantic page structure and content.
- `styles/style.css`: external styling, colour system, layout, and responsive breakpoints.
- `ASSIGNMENT-NOTES.txt`: instructor theory tasks, CSS method examples, and photo sources.

## Design direction

Little Lemon uses a warm cream, olive, and lemon palette with editorial serif typography. The page includes a cafe hero, brand story, menu highlights, quote feature, visit details, and contact link.

## Image credits

Photography comes from the Pexels URLs supplied in the assignment and additional Pexels selections listed in `ASSIGNMENT-NOTES.txt`.
