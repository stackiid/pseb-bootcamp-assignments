# Full-screen CSS Penguin | Assignment 5

A full-screen, responsive winter scene with the penguin recreated from the original supplied HTML
structure. The visible interface has no text.

## Features

- Original penguin structure and CSS-created body parts.
- Full-viewport winter background and layered snowfall.
- Breathing, blinking, and subtle wing animation.
- Hover-triggered laughing face and walking movement.
- Responsive sizing and reduced-motion support.
- HTML and CSS only. No JavaScript or external assets.

## Run

Open `index.html` in a modern browser. Hover anywhere over the scene to trigger the penguin's
laughing and walking state.
